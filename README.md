# Rusty

Rusty is a simple WhatsApp Bot

## Featues

- Send Messages
- Receive Messages
- Perform actions via command text
- Database Storage

## Acknowledgements

This project was built using the [whatsapp-rust](https://github.com/oxidezap/whatsapp-rust) third-party WhatsApp API library.
